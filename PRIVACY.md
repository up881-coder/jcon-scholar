# JCon Scholar Privacy Policy

**Effective date: September 26, 2026**

JCon Scholar - Journal & Conference Rankings ("JCon Scholar") helps users identify journals and conferences on supported academic databases and publisher websites and displays relevant ranking and metric information next to the corresponding scholarly content.

## Information processed by the extension

JCon Scholar processes only the information needed to provide its stated functionality:

1. **Publicly visible website content.** On supported academic pages, the extension reads publicly visible citation metadata such as article titles, journal names, conference names, ISSNs, and related publication information. This information is processed locally in the browser to identify the journal or conference and display matching rankings and metrics.
2. **Extension preferences.** Settings such as whether the extension is enabled, badge style, display position, and detail-display preference are stored using Chrome storage.
3. **User-imported journal metric files.** If a user voluntarily imports a CSV file containing journal metrics, that file and its import status are stored locally in Chrome extension storage and are used only for local matching and display.

## Information JCon Scholar does not collect

JCon Scholar does not collect names, email addresses, account identifiers, passwords, authentication data, payment information, personal communications, precise location, health records, or other personally identifiable information. Academic article content that mentions a disease or medical topic is treated only as public publication metadata and is not interpreted as information about the user.

## Use of information

The processed information is used solely to provide JCon Scholar's single purpose: identifying journals and conferences and displaying corresponding rankings and metrics on supported academic pages.

## Data transmission and sharing

JCon Scholar does not transmit page content, browsing activity, extension preferences, or imported CSV data to the developer or to third parties. It does not sell user data, use data for advertising, or use analytics or tracking services. Project or help links are opened only when the user chooses to click them, and no page content is appended to those links.

## Storage and retention

Extension preferences are stored through Chrome storage. User-imported CSV data is stored locally through Chrome extension storage. Users may delete imported data from the extension settings. Removing the extension deletes its locally stored extension data according to Chrome's extension-storage behavior.

## Permissions

- **Host access:** Used to recognize supported academic pages, read the publicly visible journal or conference metadata required for matching, and insert ranking labels into those pages. Unsupported pages are ignored.
- **Storage:** Used to save extension preferences and user-imported metric data.
- **Unlimited storage:** Used only to allow larger user-imported journal metric CSV files to be stored without exceeding Chrome's default extension-storage quota.

## Limited Use

JCon Scholar's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Information is used only to provide or improve the extension's disclosed, user-facing functionality.

## Changes to this policy

If this policy changes, the updated version and effective date will be published in this repository. Any material change to data practices will also be reflected in the Chrome Web Store disclosure.

## Contact

Questions about this privacy policy may be submitted through the Issues section of the public GitHub repository that hosts this document.

# JCon Scholar 隐私政策

**生效日期：2026 年 9 月 26 日**

JCon Scholar - Journal & Conference Rankings（以下简称“JCon Scholar”）用于在受支持的学术数据库和出版商网站中识别期刊或会议，并在相应学术内容旁展示匹配的等级和指标信息。

## 扩展处理的信息

JCon Scholar 仅处理实现其公开功能所必需的信息：

1. **网页中公开显示的内容。** 在受支持的学术页面中，扩展会读取公开显示的论文标题、期刊名称、会议名称、ISSN 及相关出版信息。这些信息仅在浏览器本地处理，用于识别期刊或会议并展示匹配的等级和指标。
2. **扩展设置。** 扩展是否启用、标签样式、显示位置和详细信息显示方式等设置通过 Chrome 存储功能保存。
3. **用户主动导入的期刊指标文件。** 如果用户主动导入包含期刊指标的 CSV 文件，该文件及其导入状态会保存在 Chrome 扩展本地存储中，仅用于本地匹配和展示。

## JCon Scholar 不收集的信息

JCon Scholar 不收集姓名、电子邮箱、账号标识、密码、身份验证数据、支付信息、个人通讯、精确位置、个人健康记录或其他可识别个人身份的信息。学术论文中出现的疾病或医学主题仅作为公开的出版物元数据处理，不会被解释为用户的健康信息。

## 信息用途

上述信息仅用于实现 JCon Scholar 的单一用途：识别期刊和会议，并在受支持的学术页面中展示相应等级和指标。

## 数据传输与共享

JCon Scholar 不会将页面内容、浏览活动、扩展设置或用户导入的 CSV 数据传输给开发者或任何第三方；不会出售用户数据，不会将数据用于广告，也不使用分析或跟踪服务。项目或帮助链接仅在用户主动点击时打开，且不会在链接中附加当前页面内容。

## 数据存储与保留

扩展设置通过 Chrome 存储功能保存。用户导入的 CSV 数据通过 Chrome 扩展存储保存在本地。用户可在扩展设置中删除已导入的数据。卸载扩展后，本地扩展数据将按照 Chrome 的扩展存储机制删除。

## 权限用途

- **主机访问权限：** 用于识别受支持的学术页面，读取匹配所需的公开期刊或会议元数据，并在页面中插入等级标签；不受支持的页面会被忽略。
- **storage：** 用于保存扩展设置和用户导入的指标数据。
- **unlimitedStorage：** 仅用于存储用户主动导入的较大期刊指标 CSV 文件，防止超过 Chrome 默认的扩展存储限额。

## 有限使用声明

JCon Scholar 对信息的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。所有信息仅用于提供或改进扩展已经披露的用户可见功能。

## 政策变更

如果本政策发生变化，更新后的版本和生效日期将发布在本仓库中。数据处理方式发生重大变化时，也会同步更新 Chrome Web Store 中的披露内容。

## 联系方式

如对本隐私政策有疑问，可通过托管本文件的公开 GitHub 仓库中的 Issues 功能联系。
